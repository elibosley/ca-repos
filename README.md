# ca-repos

elibosley's Community Applications repository for Unraid.

Contents:
- `ca_profile.xml` — repository overview/profile shown in CA.
- `templates/unraid-rtl8821au.xml` — **RTL88xxAU USB WiFi Driver (rtw88)** plugin
  ([source](https://github.com/elibosley/unraid-rtl8821au)): in-kernel mac80211
  driver for Realtek RTL8811AU / RTL8821AU / RTL8812AU / RTL8814AU adapters that
  Unraid ships disabled. Supports WPA3-SAE.
- `.unraid/community-apps-claim.json` — CA repo claim token.
